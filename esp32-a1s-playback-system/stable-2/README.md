# Stable 2

Versione stabile dell'impianto di riproduzione A1S orientata a una base affidabile per Wi-Fi, captive portal e selezione stream.

## Funzioni principali

- captive portal HTTP con DNS redirect
- salvataggio configurazione in NVS
- stream preset
- catalogo Icecast
- fallback configurabili
- TTS live o buffered

## Controlli osservati

- LED di stato `GPIO23`
- pulsante TTS `GPIO21`
- pulsante stazione `GPIO19`
- pulsante mount `GPIO22`
